# search.js 리팩토링 안내

기준: `master`의 `0b536e535e753d73ae3b4a36c7cfd6383b96afae`.

## 어느 파일을 수정하면 되는가

| 바꾸려는 내용 | 수정 위치 |
| --- | --- |
| 최신 연도·월, 제공할 월 목록, 성적 발표 안내 | `js/exam-config.js`의 `latest`, `getMonths`, `releaseNotices` |
| 교육과정 전환 시점, 탐구·제2외국어 목록 | `js/exam-config.js` |
| 점수 유효성, 원점수 변환, 표준점수 역산 | `js/score-calculator.js` |
| 시험 검색, 표 생성, 입력 이벤트, 결과·이미지 표시 | `js/search.js` |
| 표의 HTML 구조와 사용 안내 | `js/table-form.js` |
| 시험별 점수표와 변환 계수 | 기존 `js/data.js` |

기존 `search.js`를 화면 처리, 시험 설정, 계산 함수로 분리했다. 프레임워크나 빌드 도구는 추가하지 않았다. `jsdom`은 개발용 테스트 의존성이다.

`index.html`은 `table-form.js → data.js → exam-config.js → score-calculator.js → search.js` 순서로 불러온다. 따라서 `search.js`만 교체하면 안 된다. 이번 변경 파일을 함께 적용해야 한다.

## 유지한 동작

- 시험 옵션 변경과 표 생성 시 확정되는 시험 상태를 분리한다. 버튼을 다시 누르기 전까지 기존 표와 이미지가 다른 시험으로 바뀌지 않는다.
- 기존 6가지 표 템플릿과 HTML 이벤트 진입점을 유지한다.
- 국어·수학의 계수 적용 순서, 반올림 방식, 역산의 `0.49999` 경계 및 범위 탐색 방식을 유지한다.
- 기존 데이터 파일, 과목 이름, 이미지 경로 체계를 유지한다. 고2와 고3 데이터의 `수산∙해운` / `수산·해운` 표기 차이도 보존한다.
- 최신 시험과 연도별 월 선택지는 기존 공개 범위를 유지한다. 미래 시험 일정이 확정되면 `getMonths`와 안내 설정을 별도로 갱신해야 한다.

## 함께 수정한 오류

- 오래된 연도를 선택한 뒤 시험 유형을 바꾸면 이전 연도의 월 목록이 남던 문제: 연도를 먼저 확정하고 월 목록을 만든다.
- 선택과목의 `click` 이벤트를 `change`로 바꾸어 실제 선택 변경 시 재계산한다.
- 구교육과정 고1의 역산에서 삭제한 탐구 행을 다시 읽던 예외를 제거한다.
- 입력값의 정수·0.5점 단위 검증을 통일한다. 일부 과목에서 소수점이나 문자 뒤 숫자를 잘라 계산하던 동작을 제거한다. 역산의 유효하지 않은 선택점수는 기존 안내대로 전체 범위 계산에 사용한다.
- 빈 입력과 `0`을 구분한다. 국어·수학 역산에서 표준점수 `0`도 조회한다.
- 없는 시험 데이터는 안내를 표시한다. 없는 과목·점수 데이터는 `N/A`로 표시하고, 역조회는 빈 배열 칸을 건너뛴다.
- 통합교육과정 제2외국어의 이미지 경로는 선택된 과목 값을 사용한다.
- 통합교육과정에는 공통·선택 과목 입력을 붙이지 않는다.

자료가 없는 값을 추정하여 채우지는 않았다. 특히 `202331st` 수학에는 빈 칸과 누락된 원점수 0점 데이터가 있고, 일부 시험은 선택지에 있는 직업탐구 데이터가 없다. 원본 `data.js`는 수정하지 않았다.

## 직업탐구 행 추가

- 2026학년도 이후 고2 10월, 2027학년도 이후 고3 10월, 2028학년도 이후 모든 평가원 시험에 적용한다.
- `ExamConfig.hasVocationalInquiry`에서 표시 조건을 결정하고, `tableType5`/`tableType6`에서 과학탐구 바로 다음에 `#voc` 행을 배치한다. 원점수 표에서는 제2외국어 앞, 역산 표에서는 과학탐구 다음의 마지막 행이다.
- 과목명과 데이터 키는 `성공적인 직업생활`이다. 원점수는 0~50점의 0.5점 단위이며, 0.5·1·49·49.5점은 기존 통합탐구 규칙에 따라 제외한다. 역산 결과도 0.5점 단위로 표시한다.
- 데이터는 50점부터 0점까지 0.5점 간격의 **101행** 배열이어야 한다. 잘못된 기존 51행 자료는 `N/A`로 처리한다. 올바른 점수표가 준비되면 `data[시험키]["성공적인 직업생활"]`을 교체하면 된다. 누락된 점수를 보간하거나 실제 데이터를 수정하지 않았다.
- 직업탐구 이미지는 `printTable('voc')`, 제2외국어는 기존 `printTable(6)`을 사용하므로 행 추가로 제2외국어의 대상이 바뀌지 않는다.
- 아직 등록되지 않은 시험은 기존의 데이터 미등록/발표일 안내를 따른다. 미래 시험 테스트에서는 가상 자료로 행 배치와 연결을 검증한다.

## 새 교육과정 제2외국어·한문 점수 검증

- 기존 `ExamConfig.isIntegrated`를 사용해 교육과정을 판별한다. 고2는 2026학년도 이후, 고3 교육청은 2027학년도 이후, 평가원은 2028학년도 이후에 적용한다.
- 새 교육과정 제2외국어·한문의 1점과 49점은 불가능한 점수로 보고 `X`와 빨간 입력값으로 표시한다. 구교육과정에서는 두 점수를 계속 허용한다.
- 나머지 정수 점수와 기존 제2외국어 등급 산출식은 유지한다. 소수점 점수는 계속 허용하지 않는다.
- 화면의 유효 점수 안내에도 1점·49점 제외를 반영한다. 시험 검색 옵션만 변경한 경우에는 새 표를 만들기 전까지 기존 표의 교육과정으로 검증한다.

## 검증

```sh
npm install
npm run check
npm test
npm run test:compat
```

- `npm test`: 계산 경계, 교육과정 전환, 선택과목 변경 이벤트, 시험 상태 유지, 이미지 경로, 77개 실제 시험의 양방향 표 생성·계산을 검증한다.
- `npm run test:compat`: 기준 커밋의 `search.js`를 읽어 동일한 DOM과 실제 데이터로 구·신 구현을 실행한다. 추가된 직업탐구 행을 제외한 기존 행의 빈 입력·0점·경계 입력, 모든 선택과목, 고3·수능의 표준점수 1~200과 선택점수 6가지(빈칸 포함)를 비교한다.
- 원본이 데이터 누락으로 중단한 경우는 출력 동등성 통계에 넣지 않고 `unmatchedLegacyErrors`로 따로 기록한다. 원본의 구교육과정 고1 역산은 국어·수학 출력 후 탐구 행에서 실패하므로, 완료된 국어·수학 출력만 비교한다.
- Git 이력이 없는 경우 원본 파일 경로를 `npm run test:compat -- /path/to/original/search.js`로 전달한다.

직업탐구 추가 전 검증 결과: 자동 테스트 15개 통과. 비교 가능한 50,885개 시나리오의 출력이 원본과 일치했다. 원본이 중단한 과목 데이터 누락 68건과 빈 데이터 11건은 별도로 집계했으며, 고1 탐구 행 오류 146건은 이미 출력된 국어·수학 결과의 일치를 확인했다.

직업탐구 추가 후 검증: 자동 테스트 22개 통과. 직업탐구 표시 경계, 0.5점 입력·역산, 제2외국어와 이미지 대상 유지, 잘못된 51행 데이터 차단을 확인했다. 기존 행 50,885개 시나리오의 출력도 유지됐다.

제2외국어 규칙 추가 후 검증: 자동 테스트 26개 통과. 구·신 교육과정의 1점·49점, 나머지 점수와 등급 경계, 시험별 모든 제2외국어·한문 옵션, 입력 색상과 화면 안내, 검색 옵션 변경 시 기존 표의 상태 유지를 확인했다.

jsdom은 실제 브라우저 레이아웃이나 모바일 UI를 검증하지 않는다. 계산 동등성 검증도 기존 역산 공식의 수학적 정확성을 새로 증명하는 테스트는 아니다. 역산 알고리즘 자체의 변경은 이 리팩토링에 포함하지 않았다.
