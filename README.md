# 성적 변환 계산기

**수능·모의평가·전국연합학력평가의 원점수를 표준점수·백분위·등급으로 변환하고, 표준점수에서 원점수를 역산하는 웹 계산기입니다.**

**배포 URL: [suneungcalc.com](https://suneungcalc.com/)**

위 사이트에 접속해 시험을 선택하고 바로 계산할 수 있습니다.

[계산 코드](js/search.js) · [시험별 데이터](js/data.js)

## 프로젝트 소개

수험생이 시험별 점수의 의미를 확인할 수 있도록, 직접 정리한 통계자료와 점수 변환식을 웹 계산기로 구현했습니다. 시험과 과목을 선택해 점수를 입력하면 계산 결과가 표에 표시되고, 과목별 통계자료와 산출 공식도 함께 확인할 수 있습니다.

2018년부터 원점수별 표준점수, 백분위, 인원, 누적 비율을 정리하는 통계자료를 제작해 왔습니다. 2022학년도 수능부터 국어·수학에 공통·선택과목 체제가 적용되면서 두 점수의 조합을 다루는 계산 도구로 발전시켰고, 2024년 웹 버전을 개발했습니다. 이후 시험 자료와 교육과정 변화에 맞춰 데이터를 갱신하고 있습니다.

통계자료 제작·갱신, 계산 로직, 화면 구성과 사용 안내를 직접 담당했습니다.

## 주요 기능

| 기능 | 설명 |
| --- | --- |
| 시험 검색 | 고3 평가원, 고3 교육청, 고2 교육청, 고1 교육청 시험을 연도·월별로 선택 |
| 원점수 변환 | 과목별 원점수에 해당하는 표준점수·백분위·등급 표시 |
| 공통·선택 점수 계산 | 고3 국어·수학의 공통과목과 선택과목 점수를 각각 반영 |
| 원점수 역산 | 표준점수에 대응하는 원점수 또는 원점수 범위 표시 |
| 교육과정별 화면 | 시험 유형과 연도에 맞춰 선택과목, 통합사회·통합과학, 입력 단위 조정 |
| 통계자료 조회 | 각 과목의 점수 분포 이미지와 고3 국어·수학의 산출 공식 표시 |

2026년 9월 18일 업데이트 기준으로 **73개 시험**의 데이터를 수록하고 있습니다.

| 시험 유형 | 데이터 범위 | 시험 수 |
| --- | --- | ---: |
| 고3 평가원 | 2022~2026학년도 6월·9월 모의평가 및 수능, 2027학년도 6월 모의평가 | 16 |
| 고3 교육청 | 2022~2025년, 2026년 7월까지 | 19 |
| 고2 교육청 | 2022~2025년, 2026년 9월까지 | 19 |
| 고1 교육청 | 2022~2025년, 2026년 9월까지 | 19 |

평가원 시험은 **수능 학년도**, 교육청 시험은 **시행 연도**를 기준으로 선택합니다. 예를 들어 2026학년도 수능은 2025년에 시행된 시험입니다.

## 사용 방법

1. [계산기](https://suneungcalc.com/)에서 시험 유형과 연도·월을 선택합니다.
2. **원점수 → 표준점수/백분위/등급** 또는 **표준점수 → 원점수** 버튼을 누릅니다.
3. 선택과목을 지정한 뒤 점수를 입력합니다. 입력을 마치고 다른 칸으로 이동하면 결과가 갱신됩니다.
4. 과목 오른쪽의 **보기** 버튼으로 통계자료를 확인합니다.

고3 국어·수학의 원점수 변환에서는 **공통과목 점수와 선택과목 점수**를 함께 입력합니다. 역산에서는 **표준점수와 선택과목 점수**를 입력하면 해당 조합의 총점을 확인할 수 있습니다. 선택과목 점수를 비워 두면 원점수의 전체 범위를 보여줍니다.

영어·한국사·제2외국어/한문은 원점수에 따른 등급을 표시합니다. 과목 구성과 제공되는 결과 항목은 선택한 시험에 따라 달라집니다.

| 결과 표시 | 의미 |
| --- | --- |
| 숫자 | 입력한 점수에 대응하는 결과 |
| `80 ~ 82`와 같은 범위 | 하나의 표준점수에 대응하는 원점수 범위 |
| `X` | 입력값이 해당 항목의 허용 범위를 벗어났거나 배점상 불가능한 점수에 해당 |
| `N/A` | 점수표 조회 또는 역산에서 대응 결과를 찾을 수 없는 경우 |
| 빈칸 | 계산에 필요한 점수를 입력하기 전 상태 |

모바일에서는 **선택과목 지정 → 점수 입력** 순서로 사용합니다. 점수를 입력한 뒤 과목을 바꾼 경우에는 점수를 다시 입력해 결과를 갱신합니다.

## 계산 구조

### 시험에 맞는 입력 표 구성

[`makeTable(mode)`](js/search.js)은 선택한 시험의 연도·월·유형과 계산 방향에 따라 입력 표를 구성합니다. [`table-form.js`](js/table-form.js)에 정의한 여섯 가지 표를 사용합니다.

| 시험 구성 | 원점수 변환 | 표준점수 역산 |
| --- | --- | --- |
| 공통·선택 구분이 없는 기존 시험 | `tableType1` | `tableType3` |
| 국어·수학 공통·선택과목 시험 | `tableType2` | `tableType4` |
| 통합사회·통합과학 적용 시험 | `tableType5` | `tableType6` |

고3 교육청의 4월→5월, 고1·2 교육청의 11월→10월 변경처럼 연도별 시험 일정도 선택지에 반영합니다. 성적 발표 전으로 지정된 시험을 선택하면 발표일 안내를 표시합니다.

### 시험별 데이터 조회와 점수 변환

[`data.js`](js/data.js)는 시험별 점수표와 변환 계수를 JavaScript 객체로 보관합니다. 시험 키는 `연도 + 월 + 시험 유형`으로 구성합니다.

```javascript
// 2026학년도 수능 국어 데이터
data["202611sat"]["국어"]

// 언어와 매체의 공통점수 계수, 선택점수 계수, 상수항
data["202611sat"]["국어"][0]["언어와 매체"]
// [0.984, 0.995, 48.8]
```

[`showInfo1()`](js/search.js)은 과목의 계산 방식에 따라 결과를 구합니다.

- **고1·2 국어·수학 및 상대평가 탐구:** 원점수에 대응하는 배열 위치에서 표준점수·백분위·등급을 조회합니다.
- **고3 국어·수학:** 시험·선택과목별 계수를 사용해 표준점수를 계산하고, 해당 표준점수의 백분위·등급을 조회합니다.
- **절대평가 과목:** 원점수 구간에 따라 등급을 계산합니다.
- **통합사회·통합과학 적용 시험:** 0.5점 단위의 원점수를 점수표 위치에 대응시킵니다.

고3 국어·수학의 변환식은 다음과 같습니다.

```text
표준점수 = 반올림(a × 공통과목 점수 + b × 선택과목 점수 + c)

a, b, c: 시험·선택과목별로 저장한 계수
```

### 표준점수에서 원점수 역산

[`showInfo2()`](js/search.js)은 점수표에서 같은 표준점수를 갖는 구간을 찾거나, 변환식의 반올림 구간을 이용해 원점수 범위를 계산합니다.

- 점수표를 사용하는 과목은 일치하는 첫 위치와 마지막 위치를 찾아 원점수 범위를 구합니다.
- 고3 국어·수학에서 선택과목 점수를 입력하면, 그 점수를 고정한 상태에서 공통과목 점수의 범위를 구한 뒤 두 점수를 합산합니다.
- 선택과목 점수가 비어 있으면 공통·선택 점수 조합을 탐색해 총점의 최솟값과 최댓값을 표시합니다.

통계자료는 [`printTable()`](js/search.js)이 `img/연도/시험유형/월/과목명.png` 경로에서 불러옵니다. 고3 국어·수학에는 같은 시험 폴더의 `공식.png`도 함께 표시합니다.

## 기술과 파일 구성

**HTML · CSS · JavaScript**를 사용하며, 브라우저에서 데이터를 읽고 계산 결과를 표시합니다. 화면은 DOM 이벤트와 여섯 가지 HTML 표 템플릿으로 구성했습니다.

```text
.
├── index.html          # 시험 검색 화면, 업데이트 내역, 서비스 안내
├── css/
│   └── index.css       # 입력 표, 버튼, 통계자료 이미지 스타일
├── js/
│   ├── data.js         # 시험별 점수표와 변환 계수
│   ├── search.js       # 시험 선택, 점수 변환·역산, 이미지 표시
│   └── table-form.js   # 여섯 가지 입력 표와 사용 안내
├── img/                # 시험·과목별 통계자료와 산출 공식 이미지
└── CNAME               # 서비스 도메인: suneungcalc.com
```
